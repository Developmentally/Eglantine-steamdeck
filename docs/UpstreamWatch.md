## Standing notes

- nx2-experimental's allocator and memory-model work (tagged [series allocator] below) should come in as one merge/rebase of origin/nx2-experimental with the fork's UMA fences re-derived on top, not as cherry-picks. The nx2:gpu 216 sparse tile remap ([series 216]) is the exception worth porting first on its own: it fixes a real leak in MKW.
- Shader lowering commits conflict in lower_to_maxwell.h because the fork edited it too. Port them by taking upstream's lowering files wholesale and re-applying the fork's deltas (ISBERD slot fix, SURED, geometry-stage ops, link-register check), then run tools/nx2/check-shaders.sh on the Deck corpora before and after.
- Deliberately not taken: 6bde8c20d1 (RADV treated like other AMD for unbound sparse images) and Boost >= 1.84 (e82731c2c9). Both are documented in SteamDeck.md.
- cce6d44af2 (execute command lists as submitted) applies cleanly and attacks the same stale-words problem as the fork's DK post-clip freeze fix (89d887c0b7). A/B both on the Deck before the next merge; whichever loses should go.
